# 智能图像处理工具 - 手写体数字识别网站

## 项目概述

这是一个专业的图像处理工具网站，专注于手写体数字识别功能。网站提供了完整的图像处理流程，从图片上传到最终的数字识别，为用户提供便捷、高效的图像处理解决方案。

## 使用方法

### 1. 图片上传
1. 点击"选择图片"按钮
2. 选择要处理的图片文件
3. 图片将显示在"原始图像"区域

### 2. 图像处理
- **单通道转换**: 点击"转换"按钮将彩色图片转为灰度
- **图片剪裁**: 点击"剪裁"按钮，然后拖拽选择剪裁区域
- **颜色调整**: 使用滑块调整亮度和对比度

### 3. 数字识别
1. 确保图片已上传
2. 点击"开始识别"按钮
3. 等待识别结果
4. 查看识别数字和置信度

### 4. 快捷键
- `Ctrl + Z`: 重置所有处理
- `Ctrl + S`: 下载处理后的图像
- `Enter`: 开始识别

## 技术实现

### 图像处理算法
- **灰度转换**: 使用加权平均法 (R*0.299 + G*0.587 + B*0.114)
- **亮度调整**: 像素值乘以亮度因子
- **对比度调整**: 使用对比度变换公式
- **图像剪裁**: Canvas API 实现精确剪裁

# 手写数字识别网站

本项目基于Flask和PyTorch，提供手写数字图片的智能识别服务，支持图片上传、批量测试和网页手写输入，界面美观简洁。

## 主要功能
- 上传PNG图片，自动识别手写数字
- 批量上传多张图片，统计识别准确率
- 网页手写输入，实时识别结果
- 识别结果页面显示图片缩略图和详细信息

## 使用说明
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 运行网站：
   ```bash
   python app.py
   ```
3. 在浏览器访问 http://127.0.0.1:5000/

## 页面介绍
- 首页：功能导航、简介、使用说明、示例图片
- 图片上传：上传单张图片，显示识别结果和图片缩略图
- 批量测试：上传多张图片，表格显示每张图片的识别结果和缩略图
- 手写输入：网页canvas手写数字，实时识别

- 结果页面和表格均有图片缩略图展示
